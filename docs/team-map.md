# Как передать свою карту команде

1. **Закрой Minecraft**, чтобы карта успела сохраниться.
2. В CurseForge открой свою сборку → меню с тремя точками → **Открыть папку**.
3. Открой `journeymap` → `data` → `mp` → папку нашего сервера.
   Обычно она называется **Steel~Soil**. Если папок несколько, выбери ту,
   в которой файлы обновлялись после последней игры на нашем сервере.
4. Выдели **две папки: `overworld` и `addon-data`**.
   Для выделения второй папки удерживай Ctrl.
5. Нажми правой кнопкой → **Сжать в ZIP-файл**.
   В Windows 10: **Отправить → Сжатая ZIP-папка**.
6. Назови архив своим ником, например `Ivan.zip`, и отправь тому, кто собирает
   общую карту команды.

**Если `addon-data` нет — отправь только `overworld`.** Карта и сведения о блоках
будут в архиве; границы колоний могут отсутствовать. Не создавай пустые файлы.

Ничего внутри папок искать или удалять не нужно. Передаётся копия файлов:
твоя карта остаётся на месте. Внутри ZIP должны сразу лежать `overworld` и,
если она есть, `addon-data`, без дополнительной папки `Ivan` или `Steel~Soil`.

В этих папках находятся изображения карты, сведения о блоках и границы колоний,
если они сохранены клиентом. Для общего обмена используются
`overworld/day`, `overworld/cache` и `addon-data/minecolonies/overworld/border.json`; остальные слои
не включаются автоматически в общую карту. Личные метки из `waypoints` и
настройки клиента передавать не требуется.

**Передавай архив из папки своей игры, а не скачанный ZIP общей карты.**
Если после прошлого обновления исследовал новые места, сначала отправь свою
карту и дождись новой общей сборки, затем устанавливай её.

## Как установить общую карту

1. Закрой Minecraft. Если есть новые исследования, сначала передай их в общую сборку.
2. Скачай `Steel-Soil-JourneyMap-latest.zip` из папки Google Drive по ссылке команды.
3. Скопируй папку своего сервера `Steel~Soil` в другое место — это резервная копия.
4. Открой скачанный ZIP. Скопируй папки `overworld` и `addon-data` из архива
   в папку своего сервера с заменой совпадающих файлов. Если `addon-data` в архиве
   нет, копируй только `overworld`. Остальные файлы оставь на месте.
5. Запусти Minecraft.

Общий ZIP содержит дневную карту, доступные сведения о поверхностных блоках
и известные границы колоний. Если участок исследован только по картинке без кэша,
сведения о его блоках могут отсутствовать.
